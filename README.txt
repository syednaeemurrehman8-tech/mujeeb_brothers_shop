MUJEEB & BROTHER'S SHOP — WEBSITE

FILES
- index.html: page structure and content
- style.css: colours, layout, responsive/mobile styles
- script.js: sample products, category filters, cart, WhatsApp ordering

HOW TO OPEN
1. Extract the ZIP file if you downloaded the ZIP.
2. Keep all three files in the same folder.
3. Double-click index.html to open the website in a browser.
4. Internet is needed for the online fashion photos and Google Fonts.

IMPORTANT CUSTOMISATION
- Open script.js in a text editor.
- Change the products array names, prices, categories, and image URLs to match your stock.
- The WhatsApp number is currently set as 92335742135 (Pakistan country code +92 plus 335742135).
  The supplied number was 0335742135, which appears shorter than a typical Pakistani mobile number.
  Please confirm/correct it before publishing so customer orders reach you.
- Replace sample images with photos of your actual products for the best result.
- This is a front-end demo; cart checkout sends an order message to WhatsApp. It does not take online payments or save orders to a database.
